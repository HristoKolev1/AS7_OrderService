# Order Service

Order management service for the **Enterprise E-commerce Platform**.

The service handles the order-related part of the purchasing process and connects the shopping cart with the payment workflow.

## Responsibilities

- Order creation and management
- Processing checkout information
- Managing order-related data
- Integration with shopping cart and payment services
- Order-related REST API operations

## Tech

Java · Spring Boot · REST APIs

## Enterprise E-commerce Platform

This service is part of a larger microservices-based e-commerce system.
